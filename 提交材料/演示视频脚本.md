# 演示视频脚本 · 5–8 分钟

> 对应大赛要求：**时长 5–8 分钟｜内容含项目介绍、核心功能演示、AI 技术亮点展示｜MP4 格式、分辨率不低于 1080p｜普通话讲解，可配字幕**

## 一、录制前准备

| 项 | 要求 |
|---|---|
| 分辨率 | **1920×1080 或更高**，浏览器缩放设为 100%，关闭书签栏 |
| 帧率 | 30 fps 即可（页面动效不复杂） |
| 录屏工具 | OBS Studio（推荐）/ Windows 自带 Xbox Game Bar / 剪映录屏 |
| 录音 | 建议用独立麦克风或手机耳机麦，避免键盘声；录音与录屏分开录，后期对齐更好剪 |
| 浏览器 | Chrome 或 Edge，提前打开开发者工具关闭，隐藏所有插件图标 |
| 准备工作 | ① 运行 `启动.cmd`，确认 <http://127.0.0.1:4190/> 可访问；② 提前清理浏览器历史推荐，避免弹窗；③ 关闭微信/QQ 等通知；④ 鼠标移动要慢而稳 |
| 字幕 | 用剪映「识别字幕」自动生成后逐句校对，重点术语（木卡姆、达瓦孜、艾德莱斯）需人工确认用字 |

## 二、分镜脚本

> 时间轴按 7 分钟设计，留有余量；旁白为普通话，可全部转为字幕。

### 段落 1｜片头（0:00 – 0:25）

| 项 | 内容 |
|---|---|
| 画面 | 黑底，居中打出标题「西北非遗 · 五省手艺影像志」，副标题「陕西 · 甘肃 · 宁夏 · 青海 · 新疆」，2 秒后淡入首页主视觉 |
| 旁白 | 「西北五省，有三百多项国家级非物质文化遗产。但想在网上一眼看懂它们，很难。」 |
| 字幕要点 | 突出「300+ 项国家级」与「看不懂」的对比 |

### 段落 2｜项目介绍：我们解决什么问题（0:25 – 1:25）

| 项 | 内容 |
|---|---|
| 画面 | 停留在首页大图；随后快速切三个对比画面：①纯文字页面 ②没有配图的页面 ③本项目的图文并茂版面 |
| 操作 | 鼠标缓缓从主视觉移到右侧缩略图条，停留 2 秒 |
| 旁白 | 「我们做了三件事。第一，给每一项非遗配真实照片和现场影像；第二，为每一项写四节结构化正文——历史、技艺、传承、冷知识；第三，把它们放进一张可以点进去的地图，并且能直接问 AI。」 |
| 字幕要点 | 三件事逐条弹出 |

### 段落 3｜首页与主视觉轮播（1:25 – 2:05）

| 项 | 内容 |
|---|---|
| 画面 | 首页全屏，展示自动轮播 |
| 操作 | ①静置 8 秒，让轮播自动切换一次，指出右下角「AUTO」与进度条；②点击缩略图切到「新疆 · 天山南北」；③鼠标移到「走进五省」按钮 |
| 旁白 | 「首页五省主视觉每六秒自动切换，右下角的缩略图可以直接跳转。这里还能看到每个省收录了多少项、多少座城市。」 |
| 字幕要点 | AUTO 轮播 / 缩略图跳转 / 省份统计 |

### 段落 4｜多维筛选与详情页（2:05 – 3:05）

| 项 | 内容 |
|---|---|
| 画面 | 进入「五省非遗」 |
| 操作 | ①点击省份「新疆」→ 结果变为 14 项；②再点门类「传统技艺」→ 收窄到 3 项；③在搜索框输入「绸」→ 高亮「艾德莱斯绸织染技艺」；④点进该条目 |
| 旁白 | 「筛选支持省份、城市、门类、关键词四维组合，条件会写进网址，可以直接分享。每一页都有四种排序。」 |
| 转场 | 进入详情页后放慢语速 |
| 旁白（续） | 「详情页固定四节：历史由来、技艺特点、传承现状、冷知识。结构统一，所以读者点开任何一项，都知道该往哪儿看。」 |
| 操作 | 向下滚动展示四节正文，再滚到底部展示上下篇导航 |

### 段落 5｜分布地图（3:05 – 4:00）

| 项 | 内容 |
|---|---|
| 画面 | 进入「分布地图」 |
| 操作 | ①等地图加载完成；②鼠标依次划过陕西、甘肃、新疆的亮点，指出颜色与省份对应；③点击「喀什」的点 → 跳到该城市列表；④返回地图，滚轮放大一次 |
| 旁白 | 「地图用高德栅格瓦片渲染，不需要任何 Key。五省用五种颜色，只给真正有收录的城市打点——现在一共三十四个点，每一个点进去都有内容，不会出现空列表。」 |
| 字幕要点 | 免 Key / 34 个点位 / 点击即达 |

### 段落 6｜AI 问答与技术亮点（4:00 – 5:40）★ 重点段落

| 项 | 内容 |
|---|---|
| 画面 | 进入「AI 问答」 |
| 操作 | ①点击预设问题「安塞腰鼓为什么在陕北？」；②展示流式回答逐字出现（**不要加速**，让评委看到流式效果）；③再追问一句「它和太平鼓有什么区别？」展示多轮上下文 |
| 旁白 | 「AI 用的是 DeepSeek，走 SSE 流式输出，所以你看到的是一个字一个字出来的，首字延迟通常在一秒以内。」 |
| 操作 | ④下滑到输入框下方，点「绑定我的 API Key」，展开面板；⑤故意填入一个错误 Key，点「校验并保存」，展示错误提示；⑥填入正确 Key，展示「已保存」与状态栏变化 |
| 旁白（续） | 「这里有个我们自己比较满意的设计：访客可以绑定自己的 Key。校验只请求模型列表接口，不会消耗 token。Key 只存在本机浏览器里，不上传服务器，公开仓库里也不会有任何密钥。」 |
| 操作 | ⑦**关键演示**：切到终端，`Ctrl+C` 停掉后端；回到页面提问；展示「离线知识库模式」仍然给出结构化答案，且没有红色报错 |
| 旁白（续） | 「我们做了三级降级。后端停掉之后，页面不会报错，而是自动用站内六十七项数据做本地作答，状态栏也会如实说明当前是离线模式。演示现场网络出问题，这个功能不会垮。」 |
| 字幕要点 | SSE 流式 / Key 只存本地 / **三级降级** |

### 段落 7｜技术架构速览（5:40 – 6:30）

| 项 | 内容 |
|---|---|
| 画面 | 切到技术文档 PDF 的「总体架构」页，或直接展示架构图 |
| 操作 | 鼠标沿架构图三条链路走一遍（浏览器 → 后端 → DeepSeek） |
| 旁白 | 「技术上是一个纯前端单页应用加一个两百行的 Node 后端，零构建、零第三方运行时依赖，克隆下来 `node server.js` 就能跑，不需要 npm install。地图用 MapLibre 加高德瓦片，坐标直接用 GCJ-02，不做二次转换——这一步做错会偏三五百米。」 |
| 字幕要点 | 零构建 / 零依赖 / 免 Key 地图 |

| 项 | 内容 |
|---|---|
| 画面 | 打开「关于」页，滚到「关于收录范围」表格 |

| 画面 | 快速闪过 `docs/` 目录与技术文档 PDF 目录页 |
| 旁白（续） | 「配套还有九篇内容文档和这份技术文档，共二十四页。」 |

| 项 | 内容 |
|---|---|

| 文字 | 「西北非遗 · 五省手艺影像志」＋「陕西 甘肃 宁夏 青海 新疆」 |

## 三、剪辑要点

| 项 | 建议 |
|---|---|
| 节奏 | 每 15–20 秒必须有一次画面变化，避免长时间静态 |
| 加速 | 除「流式回答」这一段，其余等待加载的片段可用 2–4 倍速并加轻微过渡 |
| 强调 | 关键信息用底部字幕条或画面内的方框高亮，颜色统一用项目主色 `#c0392b` |
| 音量 | 人声 -6 dB 左右，背景音乐压到 -24 dB 以下，甚至不用 BGM（评审更关注讲解） |
| 导出 | H.264 / MP4，1920×1080，码率 6–10 Mbps，音频 AAC 44.1kHz |
| 文件命名 | `西北非遗_演示视频_队伍名.mp4` |

## 四、拍摄检查清单

- [ ] 画面为 1080p，无黑边、无缩放模糊
- [ ] 时长落在 5–8 分钟之间（建议 7 分钟左右）
- [ ] 三处必备内容都在：项目介绍、核心功能演示、AI 技术亮点
- [ ] 三级降级有实际演示（停掉后端那一段）
- [ ] 全程普通话，字幕无错别字，专有名词用字正确
- [ ] 无真实 API Key 出现在画面中（填错 Key 那一段也要打码或只显示前 6 位）
- [ ] 无其他窗口、通知、浏览器历史泄露
- [ ] 导出后完整看一遍，确认音画同步
