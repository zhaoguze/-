### 部署建议

**方案 A：纯静态托管（最简单，但 AI 降级为离线知识库）**
把站点文件上传到任意静态空间（Vercel / Netlify / 对象存储均可）。注意：`server.js` 不会运行，AI 问答会自动退化为「离线知识库模式」——功能仍可用，只是没有真实大模型回答。

**方案 B：云主机部署（推荐，AI 完整可用）**

```bash
# 服务器需安装 Node 18+
git clone <仓库地址> && cd <目录>
node server.js            # 或 pm2 start server.js --name ich
```

建议用 Nginx 反向代理到 4190 端口，并开放 80/443。

> ⚠️ **不要在服务器的 `.env` 里填自己的 Key**。公开部署时，让访客在页面上「绑定我的 API Key」——既符合「密钥不得出现在公开仓库」的要求，也避免自己的额度被刷。
