## 一、整体架构

纯前端单页应用（SPA）+ 独立 Node 后端，无任何构建步骤与第三方运行时依赖。

| 文件 | 职责 |
|---|---|
| `启动.cmd` | 一键启动：起服务并打开页面 |
| `index.html` | 页面骨架、脚本装配 |
| `style.css` | 设计系统（暗色沉浸式、衬线标题、朱红点缀）与全部版式 |
| `data.js` | 数据层：67 项非遗、5 省区、37 城市、门类与级别 |
| `app.js` | 哈希路由、页面渲染、轮播、筛选、地图装配、对话交互 |
| `config.js` | 地图提供方与后端接口地址等配置项 |
| `assets/map-tiles.js` | 瓦片地图模块（MapLibre + 高德栅格瓦片） |
| `assets/img/manifest.js` | 图片映射表 |
| `assets/videos.js` | 影像清单 |
| `assets/vendor/maplibre/` | 本地化的 MapLibre GL JS 4.7.1（js + css） |
| `server.js` | 静态托管 + DeepSeek 对话代理（零第三方依赖，仅用 Node 内置模块；支持 Range） |

## 三、地图方案（合规）

- **渲染器**：MapLibre GL JS 4.7.1（本地化引入，避免 CDN 与 `file://` 跨域问题）
- **底图**：高德栅格瓦片 `webrd0{1-4}.is.autonavi.com`，**免 Key**
- **坐标**：数据层为 GCJ-02，直接上图，**不做二次坐标转换**（转换会偏移 300~500 米）
- **暗色处理**：高德仅有亮色瓦片，通过 canvas `invert(1) hue-rotate(180deg)` 滤镜转暗；DOM 标记不经过该滤镜，故使用亮色
- **兜底**：瓦片方案失败 → 高德官方 JS API（需 Key）→ 腾讯地图，页面内提示，绝不跳转外部页面
- **合规**：未使用 OSM / Google / Mapbox 等非白名单源；前端不包含任何真实 Key

## 四、AI 问答后端

`server.js` 为零依赖 Node HTTP 服务，监听 `127.0.0.1:4190`，**同时托管静态站点与对话接口**（同源，无跨域）：

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/chat` | POST | SSE 流式转发 DeepSeek 对话 |
| `/api/health` | GET | 健康检查，返回 `{ok, key, demo, model, port}` |
| 其余路径 | GET | 静态文件托管，支持 `Range`（视频可拖动进度条） |

启动：

```bash
node server.js
# 或双击项目根目录的 启动.cmd（自动启动并打开页面）
```

配置：复制 `.env.example` 为 `.env`，填入 `DEEPSEEK_API_KEY`。未配置时进入演示模式。

### 三级降级策略

问答请求失败时不会把原始报错抛给用户，而是逐级兜底：

| 状态 | 触发条件 | 表现 |
|---|---|---|
| AI 在线 | 后端启动且配置了 Key | 正常流式回答，输入框下方显示「AI 已连接 · deepseek-chat」 |
| 演示模式 | 后端启动但无 Key | 返回引导性演示回答，状态显示「演示模式」 |
| 离线知识库 | 后端未启动 / 连接失败 | 用站内 67 项数据按「项目名 / 城市 / 省区 / 门类 / 推荐」五类规则本地作答，状态显示「离线知识库模式」 |

若本地规则也匹配不到，则展示一张说明卡片，提供「重试这一次提问」按钮，而非报错文本。

### 访客自带 API Key

站点默认使用服务器 `.env` 中的 Key；访客也可以在界面上绑定自己的 Key，额度从自己的账号扣除。

| 环节 | 说明 |
|---|---|
| 存储 | 仅存于访客本机浏览器 `localStorage`，不上传服务器 |
| 校验 | `POST /api/verify`，只请求 `/models` 接口验证权限，不产生 token 消耗 |
| 传递 | 聊天请求带 `X-DeepSeek-Key` 与 `X-DeepSeek-Model` 请求头，由本机后端代转发 |
| 优先级 | 访客 Key ＞ 服务器 `.env` 中的 Key ＞ 演示模式 |
| 清除 | 面板内「清除」按钮，移除本地存储，回落到站点默认配置 |

这样即便站点没有配置任何 Key，任何访客也能填入自己的 Key 把 AI 问答跑起来。

## 五、性能优化

- 图片懒加载（`loading="lazy"` + `decoding="async"`）
- 视频 `preload="none"`，点击后才加载
- 脚本按需加载，地图 SDK 仅在地图页注入
- 尊重 `prefers-reduced-motion`，减少动效
- 关键资源本地化，无外网 CDN 强依赖

## 六、本地运行

```bash
python -m http.server 8080     # 静态站点
node server.js                 # AI 后端（可选）
```
